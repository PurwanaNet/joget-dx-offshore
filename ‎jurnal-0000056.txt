1. Topologi Perangkat Keras: "Deep-Pit Survival Node"
Papan Amlogic S905X dirakit ke dalam pelindung baja ringan (IP68) yang anti-debu dan anti-getaran, dipasang tepat di portal keluar area penggalian. Area tambang dalam sering kali mengalami pemadaman listrik dari genset utama.
Sistem ini direkayasa dengan catu daya hibrida cadangan yang inovatif. Jika suplai listrik terputus, pos ini mengandalkan generator kinetik yang dimodifikasi dari dinamo motor pencetak (printer motor) bekas. Petugas checker tambang cukup memutar tuas engkol mekanis selama 45 detik. Putaran ini menghasilkan arus DC yang distabilkan menuju modul supercapacitor, menyuplai daya komputasi sesaat yang lebih dari cukup bagi cip S905X untuk menyalakan kamera, mengambil gambar manifes/muatan, dan memproses inferensi AI luring.
2. Alur Eksekusi Pemrosesan Citra Mineral (Edge Pipeline)
Fase A: Ingesti Visual Alat Bukti Ekstraksi
Modul kamera industri memotret tumpukan material di atas bak truk secara luring. Biner Golang di dalam Armbian langsung menangkap byte-array gambar tersebut.
Mengikuti standar alat bukti audit forensik Kementerian ESDM, citra tersebut diproses melalui pipeline internal Golang untuk menaikkan skala (upscaling) resolusi menjadi kanvas tajam berukuran 3000px x 3000px.
Setelah itu, algoritma secara matematis memotong (crop) kanvas tersebut untuk mengunci rasio aspek vertikal secara mutlak pada 9:16. Penguncian ini memastikan bahwa saat data disinkronkan ke pusat, inspektur tambang dapat menganalisis tekstur bebatuan secara fullscreen di layar smartphone mereka tanpa mengalami distorsi piksel atau layout shifting.
Fase B: Inferensi Luring Kadar Mineral (Edge SLM)
Pustaka model AI ringan (Small Vision Model) berbasis C++ NCNN memproses gambar secara luring pada memori RAM 1GB. AI ini menghitung Indeks Kepadatan Mineral ($M_{grade}$) untuk memverifikasi apakah muatan tersebut benar-benar bijih nikel bermutu tinggi atau sekadar tanah biasa:
$$M_{grade} = \frac{1}{\mathcal{A}} \iint_{\Sigma} \left( \Gamma(x,y) \cdot \Phi_{ore}(x,y) \right) \,dx\,dy - \lambda \cdot \Delta_{impurity}$$
(Di mana $\Gamma(x,y)$ adalah ekstraksi spektrum warna/tekstur dari gambar resolusi tinggi, $\Phi_{ore}$ adalah matriks referensi mineral standar, dan $\Delta_{impurity}$ adalah rasio deteksi limbah/slag dalam muatan pada proyeksi 9:16).

4. Manajemen DOM UI & Kendali SLA Front-End
Di Command Center Joget DX pusat, verifikator memantau ratusan antrean foto muatan 9:16. Untuk menjaga Service Level Agreement (SLA) operasional agar conveyor belt pabrik smelter tidak berhenti, form persetujuan di UI Joget menggunakan hitung mundur (countdown timer) berbasis JavaScript.
Logika hitung mundur ini wajib diisolasi dan dideklarasikan variabelnya pada global scope:
JavaScript
// Deklarasi global di level form untuk memungkinkan intervensi dari luar fungsi
var iv; 

function startHaulingClearanceSLA(durationInSeconds) {
    if (typeof iv !== 'undefined') clearInterval(iv);
    
    var timer = durationInSeconds;
    iv = setInterval(function () {
        // Manipulasi UI countdown untuk render sisa SLA...
        if (--timer < 0) {
            clearInterval(iv);
            autoApproveToSmelter();
        }
    }, 1000);
}
Deklarasi var iv; di luar fungsi ini adalah pengaman arsitektur yang krusial. Apabila inspektur melihat ketidakwajaran pola bebatuan pada foto 9:16 dan menekan tombol "Hold - Suspect Anomaly", antarmuka UI dapat seketika mengeksekusi clearInterval(iv). Fungsi ini akan langsung mematikan hitung mundur, menahan status manifes pada waiting_for_approval = 1, dan mencegah dump truck menurunkan muatan fiktifnya ke dalam crusher mesin utama.
