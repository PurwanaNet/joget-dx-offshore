1. Topologi Perangkat Keras: "Rural Kitchen Survival Node"
Papan Amlogic S905X dirakit ke dalam casing akrilik kedap uap air dan minyak (IP65) yang dipasang di atas meja distribusi kantin sekolah. Mengingat banyak sekolah pedalaman belum memiliki aliran listrik PLN yang stabil 24 jam, sistem ini direkayasa dengan catu daya mandiri berbasis energi kinetik.
Inovasi mekanisnya memanfaatkan dinamo dari motor pencetak (printer motor) bekas yang dirangkai dengan tuas engkol. Saat listrik padam, guru atau petugas katering cukup memutar engkol manual tersebut selama kurang dari satu menit. Energi mekanis ini dikonversi menjadi arus DC stabil menuju supercapacitor, memberikan daya instan bagi cip S905X untuk melakukan proses booting, menghidupkan modul kamera web USB, mengeksekusi AI luring, dan mencatat log distribusi makanan hari itu.
2. Alur Eksekusi Pemrosesan Citra Forensik Luring (Edge Pipeline)
Fase A: Ingesti Visual Alat Bukti Porsi Makanan
Kamera memotret baki makanan anak sekolah secara luring. Biner Golang pada Armbian langsung mengunci byte-array gambar mentah tersebut.
Agar foto ini sah sebagai alat bukti audit pencairan dana negara dan memiliki detail piksel yang cukup untuk membedakan tekstur serat daging sapi asli dengan protein nabati olahan, pipeline Golang mengeksekusi upscaling gambar menjadi kanvas absolut beresolusi 3000px x 3000px.
Algoritma kemudian memotong (cropping) spasial gambar tersebut untuk mengunci rasio aspek vertikal secara mutlak pada 9:16. Standardisasi 9:16 ini krusial; saat data disinkronisasi ke server pusat, auditor BGN dapat menginspeksi mikrotekstur makanan secara fullscreen di layar smartphone mereka tanpa mengalami distorsi piksel atau layout shifting pada antarmuka.
Fase B: Inferensi Luring Kepatuhan Gizi (Edge SLM)
Pustaka Small Vision Model berbasis C++ NCNN memproses gambar 9:16 secara luring di bawah alokasi RAM 1GB S905X. AI ini secara matematis menghitung Indeks Kepatuhan Nutrisi ($N_{compliance}$) per baki makanan:
$$N_{compliance} = \frac{1}{\mathcal{A}} \iint_{\Omega} \left( \nabla I_{3000}(x,y) \cdot \Phi_{nutrition}(x,y) \right) \,dx\,dy - \lambda \cdot \Delta_{deficit}$$
(Di mana $\nabla I_{3000}$ adalah gradien fitur lauk-pauk pada resolusi tinggi, $\Phi_{nutrition}$ adalah matriks referensi standar protein/kalori BGN, dan $\Delta_{deficit}$ adalah rasio deteksi karbohidrat berlebih/kosong pada proyeksi 9:16).
3. Sinkronisasi Asinkron & Protokol Isolasi Joget DX v9
Semua hasil scoring gizi terenkripsi AES-256 di dalam eMMC S905X. Ketika mobil pengawas distrik melintas dan membawa perangkat router mifi, atau saat bandwidth VSAT sekolah aktif, data JSON ditransmisikan secara asinkron ke server Joget DX pusat.
Karantina Basis Data Pembayaran Vendor Katering:
Untuk mencegah sistem pusat melakukan otomatisasi pembayaran (auto-disbursement) kepada vendor katering yang melakukan fraud (misal: porsi protein kurang), skrip SQL penerima pada Joget dilarang menulis langsung ke tabel pembayaran akhir. Kueri diwajibkan untuk menahan data dengan menyertakan kolom temporary bernama waiting_for_approval:

INSERT INTO tbl_mbg_vendor_payout_staging (

Dana negara tertahan dengan status waiting_for_approval = 1 hingga auditor regional menyetujuinya.
4. Manajemen DOM UI & Kendali SLA Pencairan Dana
Di Command Center BGN, auditor memantau ratusan ribu antrean foto baki makanan berorientasi 9:16 pada UI form Joget DX. Demi mempertahankan SLA layanan (Service Level Agreement) agar vendor katering lokal segera dibayar (maksimal 3 hari kerja untuk menjaga arus kas UMKM), antarmuka menggunakan hitung mundur (countdown timer) berbasis JavaScript.
Logika hitung mundur ini wajib dideklarasikan variabelnya pada tingkat global scope untuk memungkinkan interupsi fungsi:
JavaScript
// Deklarasi global agar saat sebelum call startCountdown bisa clearInterval terlebih dahulu
var iv; 

function startVendorPayoutSLA(durationInSeconds) {
    if (typeof iv !== 'undefined') clearInterval(iv);
    
    var timer = durationInSeconds;
    iv = setInterval(function () {
        // Manipulasi DOM untuk sisa waktu SLA di UI...
        if (--timer < 0) {
            clearInterval(iv);
            autoApprovePayoutToVendor();
        }
    }, 1000);
}
Deklarasi var iv; di luar fungsi ini adalah pengaman arsitektur anti-korupsi. Apabila auditor melihat kejanggalan komposisi lauk pada foto resolusi tinggi 9:16 dan menekan tombol "Hold - Suspect Fraud", antarmuka UI seketika mengeksekusi clearInterval(iv). Fungsi ini akan mematikan hitung mundur, menahan status pembayaran pada waiting_for_approval = 1, dan mengirimkan peringatan ke polisi wilayah setempat.
