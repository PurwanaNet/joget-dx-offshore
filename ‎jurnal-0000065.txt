1. Topologi Perangkat Keras: "The Localhost Power Broker"
Papan Amlogic S905X dirakit ke dalam casing tahan panas yang dipasang berdekatan dengan Solar Charge Controller (MPPT) dan Inverter. SBC ini tidak membutuhkan adaptor listrik terpisah; ia ditenagai langsung dari sistem sirkuit penurun tegangan (step-down/buck converter) DC-to-DC yang mengambil arus 5V stabil langsung dari bank baterai utama.
Komunikasi data dilakukan murni secara fisik. Biner Golang di dalam Armbian membaca protokol serial (Modbus RTU via kabel RS485-to-USB) langsung dari port komunikasi MPPT dan BMS (Battery Management System). Node ini memancarkan sinyal Wi-Fi lokal sehingga pemilik rumah atau pengelola fasilitas dapat memantau arus masuk/keluar (Watt/Ampere) secara real-time via browser smartphone tanpa memakan kuota internet 1 Byte pun.
2. Alur Eksekusi Telemetri & Prediksi Luring (Edge Pipeline)
Mengingat RAM S905X sangat terbatas (1GB/2GB), biner Golang harus mengeksekusi agregasi puluhan ribu baris data log daya harian secara efisien langsung ke dalam database SQLite di dalam partisi eMMC, tanpa membuat memori meluap (Out of Memory).
Fase A: Penyerapan Telemetri & Kompresi Time-Series
Setiap detik, Golang meng-ekstrak tegangan PV (Panel Surya), tegangan Baterai, dan arus beban. Alih-alih menyimpan jutaan baris data mentah yang akan menghancurkan lifespan eMMC, algoritma melakukan downsampling asinkron. Data diagregasi menjadi rata-rata per 5 menit sebelum di-commit ke disk.
Fase B: Inferensi Degradasi Baterai (Edge Math Model)
Tanpa perlu koneksi ke cloud, sistem menjalankan model matematika terkuantisasi (ditulis dalam C++) untuk memprediksi State of Health (SoH) atau tingkat kerusakan sel baterai berdasarkan riwayat kebiasaan pemakaian beban di malam hari.
Kalkulasi prediktif kelelahan sel ($SoH_{predict}$) dihitung menggunakan persamaan pelepasan elektrokimia termal:
$$SoH_{predict} = SoH_{current} - \int_{t_0}^{t} \left( \alpha \cdot I_{discharge}^2 \cdot e^{\frac{-E_a}{R \cdot T(t)}} \right) dt + \lambda \cdot \text{CyclePenalty}$$
(Di mana $I_{discharge}$ adalah arus penarikan beban, $E_a$ adalah energi aktivasi termal dari sensor suhu $T(t)$, dan $\text{CyclePenalty}$ adalah konstanta penalti jika tegangan dibiarkan drop di bawah batas aman).

4. Manajemen DOM UI PWA & Kendali Interupsi Global Scope
Keunggulan utama untuk pengguna akhir (B2C) adalah aplikasi PWA luring. Jika sistem mendeteksi cuaca mendung seharian dan kapasitas baterai menurun drastis di malam hari, UI akan memunculkan peringatan "Critical Load Shedding" (Pemutusan Beban Kritis) yang meminta pengguna mematikan alat elektronik berat dalam hitungan waktu mundur, atau sistem aktuator relay akan memutus arus secara paksa.
Arsitektur logika hitung mundur di PWA ini wajib mengisolasi variabel kontrolnya langsung di tingkat global scope agar fungsi deteksi intervensi fisik (misal pengguna memencet tombol override di layar) dapat menghentikan eksekusi pemutusan:
JavaScript
// Dideklarasikan di global scope agar intervensi manual (override) dapat membatalkan pemutusan arus
var iv; 

function startSmartLoadShedding(durationInSeconds) {
    if (typeof iv !== 'undefined') {
        clearInterval(iv);
    }
    
    var timer = durationInSeconds;
    iv = setInterval(function () {
        // Manipulasi DOM HTML5 untuk merender peringatan kedip merah...
        if (--timer < 0) {
            clearInterval(iv);
            triggerHardwareRelayCutoff(); // Mengeksekusi API Golang lokal untuk memutus relay Inverter
        }
    }, 1000);
}
Deklarasi var iv; di luar fungsi memastikan kelancaran eksekusi event loop JavaScript peramban, terutama di smartphone berspesifikasi rendah, tanpa memicu kebocoran memori (memory leak).
