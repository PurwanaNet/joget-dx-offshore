1. Topologi Perangkat Keras: "Solar-Powered Deep Mine Node"
Papan S905X di-flash secara presisi ke dalam memori internal eMMC (menghindari limitasi bottleneck MicroSD) dan dirakit ke dalam casing industrial NEMA 4X yang kedap debu bijih besi dan tahan ledakan (explosion-proof).
Mengingat lokasi site tidak memiliki colokan listrik yang dapat diandalkan, node ini ditenagai oleh sistem panel surya off-grid berkapasitas 50W. Arus dari panel surya diatur oleh modul MPPT (Maximum Power Point Tracking) yang tidak hanya mengisi daya baterai LiFePO4 12V, tetapi juga melakukan data logging voltase secara luring. Aliran daya ini memastikan SBC S905X dapat terus menyala 24/7, memancarkan sinyal Wi-Fi lokal (Captive Portal) di kedalaman tambang atau area smelter.
2. Alur Eksekusi PWA & Edge Vision AI (Luring)
Pekerja yang baru turun dari dump truck terhubung ke Wi-Fi lokal node ini menggunakan smartphone mereka dan membuka aplikasi PWA berbasis HTML5.
Fase A: Inspeksi APD Berbasis AI (Computer Vision)
Sebelum sistem mengizinkan akses ke menu absensi atau HCM, pekerja wajib membuka kamera PWA. Biner Golang menangkap byte-array citra pekerja, mengompresinya secara optimal, dan mengeksekusi model C++ NCNN terkuantisasi di bawah RAM 1GB. AI secara matematis menghitung Indeks Kepatuhan Keselamatan ($S_{compliance}$) luring:
$$S_{compliance} = \frac{1}{N} \sum_{i=1}^{N} \left( \alpha \cdot \mathbb{P}(H_i) + \beta \cdot \mathbb{P}(V_i) \right) - \gamma \cdot \iint_{\Omega} \nabla F_{fatigue}(x,y) \,dx\,dy$$
(Di mana $\mathbb{P}(H_i)$ adalah probabilitas helm proyek terdeteksi, $\mathbb{P}(V_i)$ adalah deteksi rompi reflektor, dan $F_{fatigue}$ adalah matriks gradien fitur kelelahan wajah dari pembacaan mikrotekstur area mata).
Fase B: Modul HCM Luring & Manajemen Cuti
Setelah lulus deteksi APD, pekerja masuk ke menu HCM. Mereka dapat mengajukan cuti, atau bahkan membatalkan cuti (Cancel Leave & Rollback) secara luring. Logika rollback dieksekusi langsung oleh biner Golang lokal, memperbarui kuota cuti pada database SQLite di dalam eMMC S905X.

4. Manajemen DOM UI & SLA HR Approval
Di Command Center HRD pusat, staf HR memantau antrean permintaan dari site pada antarmuka Joget. Untuk memastikan SLA penanganan cuti dan insiden harian berjalan cepat, antarmuka dikendalikan oleh countdown timer JavaScript.
Untuk mencegah bentrokan eksekusi asinkron dari berbagai plugin form Joget, variabel pengontrol wajib diisolasi di global scope:
JavaScript
// Dideklarasikan di global scope agar intervensi manual (seperti tolak cuti) dapat menghentikan SLA
var iv; 

function startHcmApprovalSLA(durationInSeconds) {
    if (typeof iv !== 'undefined') {
        clearInterval(iv);
    }
    
    var timer = durationInSeconds;
    iv = setInterval(function () {
        // Manipulasi DOM Joget DX untuk update visual sisa waktu HR...
        if (--timer < 0) {
            clearInterval(iv);
            autoApproveLeaveRollback(); // Automasi persetujuan jika HR melebihi batas waktu SLA
        }
    }, 1000);
}
Jika HR menemukan anomali (misal pekerja mengajukan rollback cuti namun terdeteksi kelelahan parah dari log AI), HR menekan tombol "Hold - Medical Review". UI seketika memanggil clearInterval(iv), mengunci status waiting_for_approval = 1, dan meneruskan data ke klinik site.
