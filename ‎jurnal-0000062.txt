Akibatnya, mereka harus membawa tumpukan dokumen kertas, rawan hilang, rawan dimanipulasi (KTP palsu), dan proses pencairan kredit tertunda berminggu-minggu.

Nama Produk: "Fin-Edge: Off-Grid Biometric KYC & Micro-Credit Node"
Kategori: B2B Perbankan / Fintech / OCR & Identifikasi Dokumen / Edge Vision AI.
Target Konsumer: Bank BUMN (Penyalur KUR), Koperasi Simpan Pinjam, Lembaga Pembiayaan Mikro, dan Auditor OJK.
Platform Utama: Biner Golang yang bertindak sebagai Localhost API Gateway dan pengolah citra luring pada OS Armbian di dalam Single Board Computer (SBC) Amlogic S905X (eMMC 8GB, RAM 1GB/2GB). Perangkat ini memancarkan Wi-Fi lokal (Captive Portal) untuk smartphone mantri bank, dan menyinkronkan data secara asinkron ke Joget DX v9 Enterprise di Data Center bank.
1. Topologi Perangkat Keras: "The Banker's Saddlebag Node"
Papan Amlogic S905X dirakit ke dalam casing portabel (IP65) seukuran power bank tebal. Karena mantri bank mayoritas bergerak menggunakan sepeda motor ke pelosok, perangkat ini ditenagai langsung melalui adaptor 12V dari aki motor atau power bank standar.
Saat perangkat menyala, biner Golang mengeksekusi hostapd pada Armbian untuk membuat jaringan Wi-Fi lokal tak berinternet (misal: SSID: BankNode-Luring). Mantri bank terhubung ke Wi-Fi ini via browser smartphone (PWA) untuk mengunggah foto KTP calon debitur, foto tempat usaha, dan foto swafoto (selfie) biometrik langsung ke server S905X di keranjang motornya.
2. Alur Eksekusi Pemrosesan Dokumen Luring (Edge OCR & AI Pipeline)
Mengingat RAM S905X hanya 1-2GB, biner Golang harus mengelola alokasi memori menggunakan teknik Memory-Mapped Files (mmap) agar proses Computer Vision tidak mengalami Out of Memory (OOM).
Fase A: Luring OCR & Ekstraksi Dokumen
Biner Golang menerima byte-array foto e-KTP. Algoritma melakukan normalisasi geometris, meratakan perspektif KTP yang miring, dan meningkatkan ketajaman (upscaling) secara lokal.
Pustaka Optical Character Recognition (OCR) ringan (C++ dikompilasi ke eksekusi Go) membaca NIK, Nama, dan Alamat, mengubahnya menjadi string JSON di lokasi tanpa sinyal.
Seluruh foto bukti (KTP, Usaha, Wajah) dipotong (crop) secara presisi ke rasio 9:16 dan di-enkripsi menggunakan AES-256-GCM ke dalam eMMC 8GB, memastikan standar keamanan data OJK terpenuhi meski perangkat dicuri.
Fase B: Inferensi Luring Biometrik Anti-Fraud (Edge SLM)
Pustaka Small Vision Model berbasis C++ NCNN memproses pencocokan wajah (KTP vs Selfie) secara luring. AI mengeksekusi matematis Indeks Kepercayaan KYC ($K_{score}$):
$$K_{score} = \alpha \cdot \text{Sim}(F_{ktp}, F_{selfie}) + \beta \cdot \text{OCR}_{conf}(I_{doc}) - \gamma \cdot \Delta_{blur}$$
(Di mana $\text{Sim}$ adalah jarak Euclidean dari vektor wajah 128-dimensi KTP dan Selfie, $\text{OCR}_{conf}$ adalah tingkat kepastian pembacaan piksel NIK, dan $\Delta_{blur}$ adalah penalti jika foto tempat usaha terdeteksi buram/dimanipulasi).
3. Sinkronisasi Asinkron & Protokol Isolasi Joget DX v9
Saat mantri bank kembali ke kantor cabang atau mendapat sinyal 4G/VSAT, biner Golang mendeteksi internet dan memicu webhook. Payload JSON berisi data KTP hasil OCR dan gambar terenkripsi ditransmisikan ke endpoint API Joget DX v9 Enterprise.

4. Manajemen DOM UI & Kendali SLA Komite Kredit
Di Credit Command Center tingkat regional, Credit Analyst memantau antrean foto KTP dan tempat usaha yang seragam berorientasi 9:16 di antarmuka Joget. Untuk memastikan SLA pencairan KUR harian (One Day Approval), antarmuka dikendalikan oleh countdown timer berbasis JavaScript.
Untuk mencegah interupsi asinkron dari DOM event listener lain, variabel pengontrol timer harus berada di global scope:
JavaScript
// Dideklarasikan di global scope agar interupsi fraud-check bisa menghentikan SLA
var iv; 

function startCreditApprovalSLA(durationInSeconds) {
    if (typeof iv !== 'undefined') {
        clearInterval(iv);
    }
    
    var timer = durationInSeconds;
    iv = setInterval(function () {
        // Manipulasi DOM Joget untuk merender sisa waktu analisis kredit...
        if (--timer < 0) {
            clearInterval(iv);
            autoEscalateToHeadManager(); // Jika waktu habis, eskalasi ke manajer, jangan auto-approve
        }
    }, 1000);
}
Jika analis menemukan ketidakcocokan antara hasil ekstraksi OCR Golang dengan foto fisik KTP 9:16 di layar (indikasi KTP tempelan), analis menekan "Reject - Fraud". UI akan mengeksekusi clearInterval(iv), menghentikan SLA, mengubah status waiting_for_approval = 0, dan menolak pengajuan tersebut secara permanen ke database blacklist.
