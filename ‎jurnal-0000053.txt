1. Topologi Perangkat Keras: "Extreme Canopy Survival Node"
Papan Amlogic S905X dirakit dalam boks taktis polikarbonat (IP68) yang dipegang oleh jagawana atau dipasang di portal pos pemeriksaan jalur hauling hutan. Mengingat kanopi hutan yang lebat sering kali menghalangi sinar matahari untuk panel surya, sistem ini wajib memiliki sumber daya mandiri.
Inovasi catu dayanya menggunakan generator kinetik mekanis yang direkayasa dari dinamo motor pencetak (printer motor) bekas. Jika daya baterai habis di tengah hutan, petugas pemeriksa cukup memutar engkol manual selama 45-60 detik. Putaran mekanis ini memberikan tegangan DC yang distabilkan untuk mengisi supercapacitor, menyuplai daya komputasi yang cukup bagi S905X untuk satu siklus pemindaian forensik.
2. Alur Eksekusi Pemrosesan Citra Forensik Luring
Fase A: Ingesti Visual Alat Bukti Logistik
Saat kayu gelondongan atau hasil panen diperiksa, modul kamera mengambil citra penampang lintang kayu (merekam cincin tahunan/serat kayu). Biner Golang di dalam Armbian langsung menangkap gambar mentah tersebut.
Sebagai standar alat bukti audit lingkungan internasional, algoritma langsung merender ulang dan menaikkan skala (upscaling) kanvas gambar menjadi resolusi absolut 3000px x 3000px.
Setelah itu, kanvas dipotong (crop) untuk mengunci rasio aspek vertikal pada 9:16. Standardisasi 9:16 ini sangat krusial agar saat data disinkronisasi ke server pusat, auditor lingkungan dapat menginspeksi foto tersebut secara fullscreen di smartphone mereka untuk menghitung cincin kayu tanpa ada distorsi gambar atau pergeseran antarmuka (layout shifting).
Fase B: Inferensi Biometrik Tumbuhan (Edge SLM)
Pustaka Small Vision Model berbasis C++ NCNN memproses gambar luring pada RAM 1GB S905X. Model ini menghitung Indeks Otentikasi Spesies ($S_{auth}$) untuk membedakan kayu produksi dari kayu hutan lindung berdasarkan kepadatan cincin dan tekstur kulit kayu:
$$S_{auth} = \frac{1}{A} \iint_{\Omega} \left( \nabla I(x,y) \cdot \Phi_{species}(x,y) \right) \,dx\,dy - \lambda \cdot P_{anomaly}$$
(Di mana $\nabla I(x,y)$ adalah gradien tekstur gambar beresolusi tinggi, $\Phi_{species}$ adalah matriks filter spesies referensi, dan $P_{anomaly}$ adalah probabilitas deteksi penyakit atau manipulasi cat pada kayu).
3. Sinkronisasi Asinkron & Protokol Isolasi Joget DX v9
Data hasil survei dienkripsi dalam eMMC 8GB S905X. Saat truk logistik tiba di pabrik penggergajian (sawmill) yang memiliki akses Wi-Fi, payload JSON ditembakkan secara asinkron ke endpoint API Joget DX v9 Enterprise di Jakarta.

Sistem dilarang keras secara otomatis mencatatkan status "Clearance" pada database utama hanya berdasarkan AI lokal. 4. Manajemen DOM UI & Kendali Global Scope
Di Command Center Joget DX, auditor memantau antrean foto penampang kayu 9:16. Untuk menjaga efisiensi bongkar muat di pabrik, form persetujuan dilengkapi hitung mundur (countdown timer) batas waktu SLA inspeksi.
Arsitektur logika hitung mundur JavaScript pada form builder Joget DX wajib mengisolasi variabelnya pada lingkup global:
JavaScript
// Deklarasi global di level form untuk visibilitas fungsi eksternal
var iv; 

function startTimberAuditSLA(duration) {
    if (typeof iv !== 'undefined') clearInterval(iv);
    var timer = duration;
    iv = setInterval(function () {
        // Manipulasi UI countdown di form Joget...
        if (--timer < 0) {
            clearInterval(iv);
            autoEscalateToMinistry();
        }
    }, 1000);
}
Implementasi global var iv; adalah fitur pengaman tingkat lanjut. Jika auditor melihat kejanggalan pada serat kayu di foto 9:16 dan menekan tombol "Hold - Suspect Illegal Logging", antarmuka eksternal dapat seketika memanggil clearInterval(iv). Ini langsung membekukan sisa waktu, mengunci data manifes secara permanen di status waiting_for_approval, dan mencegah mesin pabrik memproses kayu ilegal tersebut.
