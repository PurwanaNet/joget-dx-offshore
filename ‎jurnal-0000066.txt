1. Topologi Perangkat Keras: "The Air-Gapped Trust Anchor"
SBC Amlogic S905X dikonfigurasi sebagai mini-server portabel tanpa layar (headless). Ditenagai hanya oleh powerbank standar 5V/2A, alat ini bertindak sebagai loket validasi berjalan.
Mantri kredit di lapangan (misalnya di area perkebunan atau pegunungan tanpa sinyal seluler) menghubungkan smartphone atau tablet mereka ke Wi-Fi captive portal yang dipancarkan S905X. Semua proses pemindaian dokumen fisik, ekstraksi teks (KTP, KK), dan verifikasi tanda tangan basah diproses 100% di dalam RAM 2GB S905X tanpa pernah menyentuh internet. Ini menjamin skor audit keamanan siber (ISO 27001) bank tetap sempurna.
2. Alur Eksekusi Forensik Dokumen Luring (Edge Pipeline)
Mengingat komputasi AI sangat berat, biner Golang menggunakan binding CGO untuk memanggil pustaka C++ NCNN terkuantisasi secara efisien, mengadopsi prinsip zero-copy memory untuk mencegah kernel panic.
Fase A: OCR & Ekstraksi Entitas Mandiri (Edge SLM)
Saat mantri memotret KTP dan Surat Keterangan Usaha (SKU) calon debitur via aplikasi HTML5 lokal, gambar diproses oleh model Convolutional Recurrent Neural Network (CRNN) berukuran 15MB di dalam eMMC.
Teks diekstrak dan diklasifikasikan ke dalam struktur JSON secara langsung (Nama, NIK, Alamat, Luas Tanah Agunan).
Fase B: Forensik Tanda Tangan & Deteksi KTP Layar (Anti-Spoofing)
Untuk mencegah penipuan di mana debitur menggunakan foto KTP dari layar handphone lain, AI melakukan analisis domain frekuensi untuk mendeteksi pola Moiré (garis piksel layar) secara matematis:
$$E_{high} = \sum_{u,v > \tau} \left\vert{} \iint f(x,y) e^{-j 2\pi (ux + vy)} dx dy \right\vert{}^2$$
(Jika energi frekuensi tinggi $E_{high}$ dari spektrum Fourier gambar $f(x,y)$ melebihi ambang batas $\tau$, dokumen tersebut langsung ditolak sebagai foto dari layar/palsu).
Sistem juga membandingkan topologi guratan tanda tangan di KTP dengan tanda tangan di dokumen aplikasi kredit untuk mencari anomali tekanan pena (ink pressure gradient).

4. Manajemen DOM UI & SLA Analis Risiko
Di kantor pusat, Analis Risiko (Risk Officer) membuka dasbor Joget DX v9 untuk menyetujui kucuran dana kredit. Karena SLA (Service Level Agreement) pencairan KUR sering kali dibatasi ketat oleh regulasi (misal maksimal 24 jam), dasbor dilengkapi dengan pengatur waktu presisi.
Untuk menjaga integritas siklus memori di sisi peramban klien saat staf HR memantau ratusan pengajuan per hari, variabel kontrol JavaScript wajib dideklarasikan di global scope:
JavaScript
// Deklarasi global scope wajib untuk mencegah overlapping interval pada DOM
var iv; 

function startCreditApprovalSLA(durationInSeconds) {
    if (typeof iv !== 'undefined') {
        clearInterval(iv);
    }
    
    var timer = durationInSeconds;
    iv = setInterval(function () {
        // Manipulasi DOM UI Joget untuk update visual sisa waktu persetujuan
        if (--timer < 0) {
            clearInterval(iv);
            autoRejectOrEscalate(); // Eskalasi ke Manajer Cabang jika analis lambat
        }
    }, 1000);
}
Jika Analis menemukan kecurigaan, mereka menekan tombol "Hold - KYC Audit". Sistem langsung mengeksekusi clearInterval(iv), mengunci waiting_for_analyst = 1, dan memberikan penugasan ulang kepada investigator lapangan.
