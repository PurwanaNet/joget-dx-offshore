1. Topologi Perangkat Keras: "Resilient Perimeter Survival Node"
Papan Amlogic S905X dimasukkan ke dalam boks die-cast militer (IP67) yang diletakkan di gerbang lintas batas tradisional atau dermaga pelabuhan rakyat terpencil. Karena letaknya yang berada di pedalaman ekstrem, pasokan listrik sering kali padam atau bahkan tidak tersedia sama sekali.
Sistem ini didukung oleh catu daya hibrida independen. Selain menggunakan sel surya portabel, sistem ini dilengkapi generator kinetik mekanis darurat yang direkayasa dari dinamo motor pencetak (printer motor) bekas yang dirangkai ulang. Jika baterai habis di malam hari atau saat cuaca buruk, petugas patroli cukup memutar tuas engkol manual tersebut selama kurang dari satu menit. Putaran mekanis ini menghasilkan arus DC stabil menuju rangkaian supercapacitor, memberikan daya instan yang cukup bagi chip S905X untuk melakukan proses booting, membaca sensor kamera, dan mengeksekusi inferensi AI visual.
2. Alur Eksekusi Pemrosesan Citra Forensik Luring (Edge Vision Pipeline)
Fase A: Ingesti Visual Alat Bukti Pabean
Saat armada pengangkut komoditas atau pelintas batas melakukan pelaporan luring, modul kamera menangkap citra segel kontainer, nomor lambung kapal, atau dokumen manifes fisik. Biner Golang di dalam Armbian langsung mengunci byte-array gambar mentah tersebut.
Agar dapat diakui sebagai alat bukti hukum forensik internasional yang tidak bisa disangkal (non-repudiation), citra diproses melalui pipeline internal untuk menaikkan skala (upscaling) resolusi gambar mentah menjadi kanvas berukuran tepat 3000px x 3000px.
Setelah kanvas resolusi tinggi terbentuk, algoritma melakukan pemotongan (cropping) geometris otomatis untuk mengunci rasio aspek vertikal pada 9:16. Standardisasi rasio 9:16 ini mutlak; ketika data berhasil disinkronisasi ke pusat, inspektur pabean atau manajemen risiko di Jakarta dapat membuka foto bukti tersebut secara penuh (fullscreen) di smartphone mereka tanpa khawatir terjadi distorsi piksel ataupun pergeseran tata letak antarmuka (layout shifting).
Fase B: Inferensi Luring Deteksi Anomali Kargo (Edge SLM)
Pustaka Small Vision Model yang dikompilasi lewat C++ NCNN mengeksekusi gambar secara luring langsung di RAM 1GB S905X. AI menghitung Indeks Resiko Penyelundupan ($R_{smuggle}$) untuk mengidentifikasi indikasi kecurangan muatan atau kerusakan segel keamanan:
$$R_{smuggle} = \frac{1}{\mathcal{K}} \iint_{\Omega} \left| \Psi_{3000}(x,y) - \Psi_{ref}(x,y) \right| \,dx\,dy + \gamma \cdot \Lambda(P_{9:16})$$
(Di mana $\Psi_{3000}$ adalah matriks fitur dari kanvas gambar resolusi tinggi, $\Psi_{ref}$ adalah tanda tangan digital cetakan segel resmi, dan $\Lambda(P_{9:16})$ adalah koefisien anomali spasial dokumen pada rasio vertikal 9:16).
3. Sinkronisasi Asinkron & Protokol Isolasi Joget DX v9
Seluruh log pemeriksaan tersimpan aman di dalam enkripsi eMMC lokal. Ketika kapal patroli atau kendaraan inspeksi berkala yang membawa router Wi-Fi melintas, data disedot secara P2P menggunakan teknik data muling. Begitu kendaraan patroli mendapatkan sinyal internet di kota terdekat, payload JSON ditembakkan via REST API menuju Joget DX v9 Enterprise.
Karantina Transaksi Database:
Untuk mencegah sistem melakukan kelulusan manifes otomatis (auto-clearance) terhadap log yang baru masuk, kueri SQL penerima dilarang keras menulis langsung pada tabel transaksi aktif. 4. Manajemen DOM UI & Kendali Interupsi Global Scope
Di Command Center pusat, manajemen puncak meninjau antrean dokumen dengan visualisasi foto berorientasi 9:16 pada UI form Joget DX. Demi menjaga kelancaran rantai pasok ekspor agar tidak terjadi penumpukan logistik, formulir persetujuan dibatasi oleh hitung mundur (countdown timer) SLA peninjauan.
Arsitektur logika hitung mundur JavaScript pada komponen form builder Joget DX wajib mengisolasi variabel kontrolnya langsung di dalam global scope:
JavaScript
// Deklarasi variabel pengontrol pada global scope agar bisa diintervensi fungsi eksternal
var iv; 

function startBorderClearanceSLA(durationInSeconds) {
    if (typeof iv !== 'undefined') clearInterval(iv);
    
    var timer = durationInSeconds;
    iv = setInterval(function () {
        // Logika manipulasi DOM untuk merender sisa waktu di UI...
        if (--timer < 0) {
            clearInterval(iv);
            autoApproveClearanceBatch();
        }
    }, 1000);
}
Penerapan var iv; di luar lingkup fungsi ini merupakan pertahanan utama sistem. Jika verifikator pusat melihat ketidaksesuaian nomor lambung kapal atau bentuk muatan pada foto 9:16 tersebut dan menekan tombol "Hold - Initiate Interdiction", sistem antarmuka Joget dapat seketika memanggil perintah clearInterval(iv) secara lintas fungsi. Hitung mundur otomatis dihentikan saat itu juga, mengunci status log pabean secara permanen pada waiting_for_approval = 1, dan mencegah sistem melakukan pelulusan manifes kargo yang mencurigakan.
