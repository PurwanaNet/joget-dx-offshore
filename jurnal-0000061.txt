1. Topologi Perangkat Keras: "Rural Node Pembangkit Mandiri"
Papan S905X dirakit ke dalam pelindung polikarbonat (IP67) yang tahan terhadap lumpur dan cuaca ekstrem persawahan. Mengingat infrastruktur listrik di lumbung pangan pedesaan sering kali tidak stabil, sistem ini direkayasa dengan catu daya kinetik hibrida.
Inovasi mekanisnya memanfaatkan generator putar yang dimodifikasi dari dinamo motor pencetak (printer motor) bekas. Petugas desa cukup memutar tuas engkol manual selama kurang dari satu menit untuk mengisi sirkuit supercapacitor. Aliran ini memberikan tegangan DC murni yang langsung menghidupkan cip S905X untuk mengeksekusi satu siklus komputasi penuh: menyalakan modul kamera, mengambil citra sampel panen, memproses AI luring, dan menyimpan log audit tanpa bergantung pada baterai litium.
2. Alur Eksekusi Pemrosesan Citra Agronomi Luring (Edge Pipeline)
Fase A: Ingesti Visual Alat Bukti Panen
Kamera menangkap foto sampel bulir gabah, daun yang terkena hama, atau dokumen fisik petani. Biner Golang pada Armbian langsung mengunci byte-array gambar tersebut.
Agar foto ini sah sebagai instrumen audit negara dan tahan terhadap perubahan format (terutama jika ke depannya terjadi penyesuaian regulasi ekonomi seperti redenominasi Rupiah yang menuntut dokumentasi aset presisi tinggi), algoritma mengeksekusi upscaling gambar mentah menjadi kanvas absolut beresolusi 3000px x 3000px.
Setelah kanvas definitif terbentuk, sistem melakukan pemotongan (cropping) geometris untuk mengunci rasio aspek vertikal secara mutlak pada 9:16. Standardisasi 9:16 ini tidak bisa ditawar; saat disinkronisasi ke server pusat, auditor pemerintah dapat menginspeksi mikrotekstur penyakit tanaman secara fullscreen di layar smartphone tanpa distorsi piksel atau layout shifting pada antarmuka.
Fase B: Inferensi Luring Valuasi Kualitas (Edge SLM)
Pustaka Small Vision Model berbasis C++ NCNN memproses gambar 9:16 secara luring di dalam batas RAM 1GB S905X. AI ini secara matematis menghitung Indeks Kualitas Kelayakan ($Q_{harvest}$) untuk mendeteksi anomali fisik atau penyakit:
$$Q_{harvest} = \frac{1}{\mathcal{H}} \iint_{\Omega} \left( \nabla I_{3000}(x,y) \otimes \Psi_{botany}(x,y) \right) \,dx\,dy - \beta \cdot \text{Defect}(P_{9:16})$$
(Di mana $\nabla I_{3000}$ adalah gradien fitur resolusi tinggi dari sampel tanaman, $\Psi_{botany}$ adalah matriks referensi patologi botani, dan $\text{Defect}$ adalah probabilitas kejanggalan/hama pada proyeksi visual 9:16).
3. Sinkronisasi Asinkron & Protokol Isolasi Joget DX v9
Semua hasil scoring panen dan dokumen KTP petani terenkripsi AES-256 di dalam eMMC lokal. Saat agen desa mendapatkan sinyal seluler sementara, atau melakukan sinkronisasi drive-by via Wi-Fi di balai kecamatan, payload JSON ditransmisikan secara asinkron ke server pusat.

4. Manajemen DOM UI & Kendali Interupsi Global Scope
Di Command Center Kementerian, auditor memantau antrean visual panen berorientasi vertikal 9:16 pada UI Joget DX. Demi mempertahankan SLA layanan (Service Level Agreement) agar petani cepat menerima dana, formulir dikendalikan oleh hitung mundur (countdown timer) berbasis JavaScript.
Arsitektur logika hitung mundur ini wajib mengisolasi variabel kontrolnya langsung di tingkat global scope agar fungsi eksternal dapat melakukan intervensi:
JavaScript
// Dideklarasikan sebagai variabel global agar saat sebelum call startCountdown bisa clearInterval terlebih dahulu
var iv; 

function startSubsidyDisbursementSLA(durationInSeconds) {
    if (typeof iv !== 'undefined') {
        clearInterval(iv);
    }
    
    var timer = durationInSeconds;
    iv = setInterval(function () {
        // Manipulasi DOM untuk merender sisa waktu di antarmuka...
        if (--timer < 0) {
            clearInterval(iv);
            autoApproveSubsidyFund();
        }
    }, 1000);
}
Deklarasi var iv; di luar fungsi ini adalah lapisan proteksi anti-korupsi. Apabila auditor melihat kejanggalan pada sampel panen di layar 9:16 tersebut (misalnya terindikasi foto gabah daur ulang) dan menekan tombol "Hold - Suspect Fraud", UI seketika memanggil perintah clearInterval(iv). Ini mematikan paksa timer, mengunci status pengajuan tetap pada waiting_for_approval = 1, dan membatalkan instruksi API pencairan dana secara permanen.
