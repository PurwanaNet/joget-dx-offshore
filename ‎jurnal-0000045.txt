Petugas terpaksa kembali menggunakan dokumen fisik, membuka celah manipulasi tanda tangan, manipulasi tanggal, atau pemalsuan identitas oleh oknum agen.

Nama Produk: "Sign-Edge: Air-Gapped Document Notarization & Forensic Vault Node"

1. Anatomi Perangkat Keras: Kotak Dekripsi Mandiri (Off-Grid Box)
SBC Amlogic S905X ditanam di dalam kotak koper taktis (IP65) yang berfungsi sebagai Offline Hardware Security Module (HSM). Untuk menjamin keberlangsungan operasional di daerah tanpa pasokan listrik PLN, koper ini mengandalkan sistem daya kinetik mandiri.
Sistem ini memanfaatkan modifikasi motor pencetak (printer motor) bekas yang dirangkai sebagai generator engkol mekanis (hand-crank generator). Cukup memutar engkol selama 45 detik, energi mekanis dikonversi menjadi daya DC yang dialirkan ke rangkaian supercapacitor untuk menghidupkan dan menjaga stabilitas tegangan papan S905X selama proses pemindaian dokumen forensik berlangsung.
2. Alur Eksekusi: "The Air-Gapped Forensic Pipeline"
Fase 1: Ingesti Visual Beresolusi Tinggi & Pemotongan Kanvas
Dokumen fisik yang telah ditandatangani diletakkan di bawah kompartemen kamera makro koper. Biner Golang di dalam Armbian langsung menangkap citra mentah (raw image) dokumen tersebut.
Untuk memenuhi standar pembuktian hukum dan kebutuhan analisis mikro-fiksasi tinta, pipeline internal mengeksekusi upscaling kanvas gambar ke resolusi 3000px x 3000px.
Setelah kanvas distandardisasi, sistem langsung melakukan pemotongan (cropping) otomatis berorientasi vertikal dengan mengunci rasio aspek pada 9:16. Penguncian rasio 9:16 ini krusial agar struktur serat kertas dan kontinuitas guratan tinta dapat diperiksa secara linear pada layar gawai (smartphone) tim hukum di kantor pusat tanpa risiko distorsi piksel atau layout shifting.
Fase 2: Analisis Ketajaman Guratan Tinta (Edge Inference)
Pustaka Small Vision Model berbasis C++ NCNN mengeksekusi komputasi luring di dalam keterbatasan RAM 1GB S905X. Sistem menghitung Nilai Verifikasi Keaslian Guratan Tinta ($S_{verify}$) menggunakan formulasi:
$$S_{verify} = \alpha \cdot \sum_{i=1}^{m} \left( \nabla^2 I_{roi}(x,y) \right) \times \exp\left(-\gamma \cdot D_{entropy}\right)$$
(Di mana $\nabla^2 I_{roi}(x,y)$ mewakili operasi matriks Laplacian pada area fokus tanda tangan untuk mendeteksi ketajaman tepi goresan—membedakan tanda tangan asli yang bertenaga dengan hasil cetak printer atau jiplakan lambat—dan $D_{entropy}$ adalah entropi distribusi kerapatan piksel tinta).
Fase 3: Sinkronisasi Tertunda & Karantina Database Joget DX v9
Log enkripsi dokumen beserta gambar berasio 9:16 disimpan ke dalam eMMC lokal yang terenkripsi AES-256. Ketika petugas lapangan kembali ke kantor cabang yang memiliki akses internet, data ditransfer via P2P (Wi-Fi lokal/Bluetooth) ke aplikasi penampung, kemudian ditembakkan ke endpoint API Joget DX v9 Enterprise.
Protokol Proteksi Audit: Mengingat data ini menyangkut legalitas akad kredit, plugin penerima di Joget DX dilarang langsung menyetujui dokumen tersebut. Kueri SQL wajib direvisi untuk menyisipkan data kontrak ke dalam tabel antara dengan menambahkan kolom temporary bernama waiting_for_approval.
Fase 4: Manajemen DOM UI & Kendali Scope Global
Di kantor pusat, tim Legal Compliance memeriksa antrean berkas melalui dasbor Joget DX v9. Terdapat fungsi countdown timer untuk membatasi waktu verifikasi manual sebelum dokumen kedaluwarsa secara hukum.
Logika hitung mundur ini wajib dibangun di level frontend dengan mendeklarasikan pengontrol interval pada lingkup global:
JavaScript
var iv; // Global scope variable

Struktur ini memastikan bahwa jika tim hukum menemukan anomali visual pada tanda tangan 9:16 tersebut dan menekan tombol "Trigger Manual Forensic Escalation", fungsi eksternal dapat dengan instan memanggil clearInterval(iv) untuk menghentikan hitung mundur tanpa memicu error atau memicu aksi penolakan otomatis dari sistem.
