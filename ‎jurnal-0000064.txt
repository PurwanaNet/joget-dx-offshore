Perangkat ini memancarkan jaringan lokal mandiri untuk operator dermaga, lalu menyinkronkan data manifestasi kargo secara asinkron ke Joget DX v9 Enterprise di pusat kontrol korporat.
1. Topologi Perangkat Keras: "The Dockside Kinetic-Resilient Mesh"
Papan S905X ditanam di dalam selubung aluminium die-cast berstandar militer (IP66) yang diletakkan tepat di atas palang gerbang masuk atau langit-langit loading dock. Karena area bongkar muat kontainer sangat fluktuatif dalam ketersediaan daya listrik AC akibat seringnya lonjakan beban dari mesin derek (crane), sistem ini direkayasa agar beroperasi secara mandiri tanpa ketergantungan pada jaringan listrik utama (Grid-Free).
Inovasi pemanen energinya memanfaatkan kombinasi modul Passive Power-over-Ethernet (PoE) Energy Harvester dengan sirkuit penyangga Supercapacitor hibrida. Sistem ini menangkap riak tegangan residual (residual low-voltage drop) yang mengalir sepanjang kabel jaringan internal gudang, menyimpannya secara instan, dan meregulasi arus DC murni konstan untuk cip S905X. Arsitektur ini menjamin node tetap menyala stabil mengeksekusi siklus pemindaian AI meskipun suplai listrik utama pabrik mengalami blackout parsial.
2. Alur Eksekusi Pemrosesan Citra Volumetrik Luring (Edge Pipeline)
Mengingat keterbatasan RAM S905X yang hanya berkisar antara 1GB hingga 2GB, biner Golang bertindak sebagai konduktor utama yang mengelola jalur memori secara zero-copy untuk mencegah terjadinya kernel panic akibat Out of Memory (OOM).
Fase A: Ekstraksi Spasial & Upscaling Kanvas Bukti
Saat truk berhenti di loading dock, kamera USB industrial yang terhubung ke S905X mengambil gambar tampak belakang bak muatan secara luring. Biner Golang langsung mengunci aliran data biner gambar tersebut.
Untuk memastikan legalitas forensik dokumen audit muatan jika terjadi sengketa hukum klaim asuransi barang di kemudian hari, gambar mentah tersebut diubah skalanya (upscaling) lewat akselerasi interpolasi linier lokal menjadi kanvas absolut beresolusi tinggi 3000px x 3000px.
Setelah kanvas resolusi tinggi terbentuk, algoritma melakukan cropping spasial geometris secara kaku untuk mengunci rasio aspek vertikal secara mutlak pada ukuran 9:16. Standardisasi dimensi 9:16 ini sangat vital; saat data berhasil terunggah ke server pusat, pihak manajemen atau auditor internal dapat memeriksa keaslian segel pengaman kargo secara fullscreen di perangkat genggam tanpa mengalami deformasi visual atau pergeseran tata letak antarmuka (layout shifting).
Fase B: Inferensi Luring Geometri Proyektif (Edge SLM)
Pustaka Small Vision Model berbasis C++ NCNN mengeksekusi segmentasi semantik pada proyeksi gambar 9:16 secara luring. AI mengeksekusi kalkulasi kalkulus tensor untuk mengestimasi volume muatan ($V_{cargo}$) berdasarkan perbedaan jarak piksel terhadap batas dinding bak truk:
$$V_{cargo} = \oint_{\partial \Omega} \left( \mathbf{J}(x,y) \cdot \mathbf{n} \right) \,ds - \mu \cdot \sum \sigma^2(P_{9:16})$$
(Di mana $\mathbf{J}(x,y)$ mewakili matriks matriks Jacobian transformasi perspektif dari koordinat piksel 2D ke estimasi ruang 3D, $\mathbf{n}$ adalah vektor normal bidang batas muatan, dan $\sigma^2(P_{9:16})$ ialah varians densitas muatan yang terdeteksi pada kanvas 9:16).
Bersamaan dengan itu, OCR luring berbasis model Character-Recognition terkuantisasi mengekstrak nomor seri segel besi kontainer untuk memastikan segel tidak dalam kondisi rusak atau bekas dibongkar paksa.
3. Sinkronisasi Asinkron & Protokol Isolasi Joget DX v9
Semua paket data manifestasi yang berisi nomor segel hasil OCR, estimasi volumetrik, dan gambar kanvas 9:16 dikompresi menjadi satu berkas terenkripsi di dalam eMMC lokal. Begitu koneksi WAN (baik via modem seluler cadangan atau jaringan Wi-Fi utama gudang) kembali pulih, biner Golang mendorong data tersebut melalui protokol asinkron ke API Gateway Joget DX v9 di kantor pusat.

4. Manajemen DOM UI & Kendali Interupsi Global Scope
Pada dasbor Control Center Joget DX v9, supervisor memantau visualisasi bak truk kontainer dalam orientasi vertikal 9:16. Untuk menjaga efisiensi perputaran antrean truk di gudang (Dock Turnaround Time), sistem ini menerapkan batas waktu pemrosesan (SLA Countdown Timer) berbasis JavaScript.
Untuk menghindari malafungsi eksekusi akibat penumpukan instantiation objek pengatur waktu di memori peramban, variabel penampung interupsi wajib ditempatkan pada tingkatan paling luar (global scope):
JavaScript
// Deklarasi variabel pada tingkat global scope untuk mencegah kebocoran alokasi interval DOM
var iv; 

function initiateDockClearanceSLA(durationInSeconds) {
    // Memastikan interval sebelumnya dibersihkan secara mutlak sebelum membuat siklus baru
    if (typeof iv !== 'undefined') {
        clearInterval(iv);
    }
    
    var timer = durationInSeconds;
    iv = setInterval(function () {
        // Logika manipulasi elemen DOM Joget untuk merender hitung mundur visual...
        if (--timer < 0) {
            clearInterval(iv);
            triggerAutomatedDiscrepancyEscalation(); // Otomatis eskalasi ke manajer jika staf lambat memeriksa
        }
    }, 1000);
}
Apabila supervisor mendeteksi adanya kecurangan nyata pada layar 9:16 (misal nomor segel kontainer tampak rusak secara fisik namun lolos pembacaan standar), supervisor menekan tombol "Flag - Discrepancy Detained". Perintah ini seketika mengeksekusi clearInterval(iv) pada global scope, memutus rantai hitung mundur otomatis, mengunci baris data pada nilai waiting_for_approval = 1, dan menerbitkan tiket investigasi ke tim sekuriti internal.
