1. Anatomi Masalah & Visi Solusi (Inventor's Perspective)
Ekskavator dan dump truck raksasa di pit tambang sering mengalami kerusakan bearing atau gearbox mendadak. Jika rusak di tengah pit, biaya downtime dan evakuasi bisa mencapai ratusan juta rupiah per jam.
Sensor getaran IoT komersial membutuhkan koneksi internet real-time ke cloud yang mustahil diakses di dasar pit tambang. AcoustiNode-Edge menyelesaikan ini dengan menempatkan komputasi langsung di dalam kabin mesin. Memanfaatkan mikrofon piezoelektrik industrial, SBC Amlogic mendengarkan "suara" mesin, memproses frekuensinya menggunakan Go, dan mendeteksi anomali logam yang bergesekan berminggu-minggu sebelum kerusakan fisik terjadi.
2. Arsitektur Komputasi Luring (The S905X Edge Pipeline)
Biner Go yang dirakit dengan GoMobile/Go-Edge beroperasi sebagai micro-server di dalam Armbian. Mengingat eMMC 8GB rentan terhadap wear-leveling jika terus-menerus ditulisi data, sistem memproses aliran audio di dalam RAM (in-memory processing).
Fase A: Digital Signal Processing (DSP) & Fast Fourier Transform (FFT)
Biner Go membaca stream audio dari mikrofon USB. Melalui pustaka FFT, gelombang suara domain waktu (time-domain) diubah menjadi domain frekuensi untuk mencari lonjakan amplitudo pada frekuensi tinggi yang identik dengan gesekan logam.
Energi frekuensi tinggi dihitung menggunakan operasi matematika di dalam rutin Go:
$$E_{anomaly} = \sum_{k=f_{min}}^{f_{max}} \vert{}X(k)\vert{}^2$$
(Di mana $X(k)$ adalah nilai spektral pada bin frekuensi $k$, mendeteksi frekuensi resonansi bearing yang aus).
Fase B: Inferensi Small Language Model (SLM) & Decision Making
Alih-alih mengirim audio ke peladen, model kuantisasi C++ (dipanggil via CGO) mengklasifikasikan pola FFT tersebut: apakah ini suara "Normal", "Kekurangan Pelumas", atau "Retak Kritis". Jika kritis, sistem langsung memicu actuator relay untuk menyalakan lampu peringatan merah di dasbor operator.
3. Protokol Sinkronisasi Joget DX v9 (The Workflow Bridge)
SBC Amlogic S905X menyimpan log insiden dalam database SQLite luring yang dioptimalkan. Saat dump truck kembali ke pangkalan (Basecamp) untuk mengisi bahan bakar, SBC akan terhubung ke Wi-Fi pangkalan secara otomatis.
Pada detik itu, script webhook terpicu untuk membuang (dump) payload JSON yang terenkripsi langsung ke REST API Joget DX v9 Enterprise.

JavaScript Trigger & Auto-Decision:
Di dalam form Joget, kita menginjeksi pemicu JavaScript pada Process Tool. Jika skor anomali sangat tinggi, sistem secara otomatis menerbitkan Surat Perintah Kerja (Work Order) kepada mekanik tanpa campur tangan manusia. Jika mekanik salah mendiagnosis dan ingin membatalkan status, kita pasang trigger pembatalan dengan API lokal:
JavaScript
// Trigger dipasang pada tombol "Cancel & Rollback WO" di UI Joget DX
function rollbackWorkOrder(processId) {
    $.ajax({
        url: '/jw/api/process/abort/' + processId,
        type: 'POST',
        headers: {
            "Authorization": "Basic " + btoa("api_user:api_key")
        },
        success: function(response) {
            alert("Work Order dibatalkan. Mengembalikan status kendaraan ke Operasional.");
            // Logika update status DOM...
        }
    });
}
