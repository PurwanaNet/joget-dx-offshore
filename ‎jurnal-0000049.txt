Nama Produk: "Batas-Guard: Air-Gapped Passport Forensic & Border SCM Node"
Kategori: B2G (Layanan Pemerintah/Imigrasi) / OCR & Doc Classifier / AI Automation / Hardware Security Node.

Platform Utama: Daemon pemrosesan biner Golang yang ditanam pada OS Armbian di dalam perangkat Single Board Computer (SBC) Amlogic S905X (eMMC 8GB, RAM 1GB/2GB). Perangkat ini bertindak sebagai Offline Forensics Node yang berkomunikasi asinkron dengan Joget DX v9 Enterprise di Command Center pusat.
1. Anatomi Perangkat Keras: Kios Forensik Swadaya (Off-Grid)
Modul Amlogic S905X dirakit ke dalam koper taktis tahan air (IP67) yang dilengkapi kompartemen pemindai paspor ber-UV. Karena PLBN terpencil sering mengalami pemadaman listrik yang melumpuhkan server lokal, koper ini ditenagai oleh sistem daya kinetik mandiri.
Sistem daya darurat ini memanfaatkan modifikasi motor pencetak (printer motor) bekas yang dirangkai menjadi generator engkol mekanis (hand-crank). Ketika listrik pos padam total, prajurit atau petugas imigrasi cukup memutar engkol selama 45 detik untuk mengisi rangkaian supercapacitor. Daya ini memberikan tegangan stabil bagi papan S905X untuk menjalankan siklus pemindaian dan enkripsi data pelintas batas secara luring.
2. Alur Eksekusi Pemrosesan Citra Forensik Luring
Fase 1: Ingesti Visual Holografik & Standarisasi Kanvas Alat Bukti
Paspor fisik diletakkan di bawah modul kamera UV/IR di dalam koper taktis. Biner Golang di dalam Armbian langsung menangkap citra mentah dari mikroteks dan hologram Machine Readable Zone (MRZ).
Sebagai standar mutlak untuk alat bukti hukum internasional, pipeline algoritma secara instan me-render ulang dan menaikkan skala (upscaling) kanvas gambar menjadi resolusi 3000px x 3000px.
Setelah resolusi terbentuk, sistem langsung melakukan pemotongan (cropping) otomatis dengan rasio aspek vertikal 9:16 (sekitar 1687px x 3000px). Penguncian rasio 9:16 ini sangat krusial; ketika data ini kelak disinkronisasi ke markas pusat, analis forensik imigrasi dapat memeriksa keaslian serat kertas dan pola watermark paspor langsung dari layar smartphone mereka tanpa mengalami pelebaran piksel atau layout shifting.
Fase 2: Inferensi SLM Luring (Edge Anomaly Analytics)
Pustaka Small Vision Model berbasis C++ NCNN mengeksekusi komputasi secara lokal pada RAM 1GB S905X. Model menghitung Indeks Keaslian Paspor ($P_{auth}$) dengan mendeteksi anomali pada font MRZ dan fiksasi tinta foto biometrik. Jika $P_{auth}$ berada di bawah ambang batas toleransi, palang pintu (actuator) tidak akan terbuka, dan alarm senyap diaktifkan.
3. Sinkronisasi Asinkron & Isolasi Ledger di Joget DX v9
Semua data pelintas batas dienkripsi di eMMC 8GB S905X. Saat jaringan satelit (VSAT) kembali menyala, atau saat kendaraan logistik membawa data (data muling) tiba di kota terdekat, payload JSON asinkron ditembakkan ke endpoint API Joget DX v9 Enterprise di Jakarta.
Karantina Database Keimigrasian:
Sistem dilarang keras secara otomatis mencatatkan status "Clearance/Lolos" pada database utama hanya berdasarkan AI lokal. Kueri SQL integrasi wajib direvisi untuk mengisolasi baris data pelintas batas ini ke dalam tabel karantina sementara, dengan menambahkan kolom temporary bernama waiting_for_approval. Data ini tertahan di fase staging investigasi hingga divalidasi oleh perwira pemeriksa.
4. Manajemen DOM Front-End & Kendali Global Scope
Di Command Center Jakarta, perwira imigrasi memantau antrean form masuk di Joget DX. Mereka dihadapkan pada foto paspor vertikal 9:16 dari berbagai PLBN. Antarmuka ini dilengkapi countdown timer untuk menentukan batas waktu investigasi (SLA) sebelum status pelintas batas dilaporkan ke aparat lokal.
Arsitektur logika hitung mundur JavaScript pada form builder Joget DX ini wajib dibangun dengan mendeklarasikan pengontrol interval pada lingkup global:
JavaScript
// Deklarasi global di level form untuk visibilitas lintas-fungsi
var iv; 

function startBorderInvestigationTimer(duration) {
    if (typeof iv !== 'undefined') clearInterval(iv);
    var timer = duration;
    iv = setInterval(function () {
        // Logika render countdown ke UI...
        if (--timer < 0) {
            clearInterval(iv);
            triggerAutoEscalationToInterpol();
        }
    }, 1000);
}
Implementasi global scope ini bukan sekadar gaya penulisan, melainkan pengaman arsitektur. Jika perwira mendeteksi manipulasi wajah pada foto 9:16 tersebut dan menekan tombol "Hold - Request Field Interrogation", eksekusi tombol eksternal tersebut dapat dengan seketika memanggil clearInterval(iv). Ini akan membekukan sisa hitung mundur secara instan, mengunci antarmuka di status waiting_for_approval, dan mencegah sistem melakukan auto-reject atau auto-approve yang berpotensi meloloskan buronan.
