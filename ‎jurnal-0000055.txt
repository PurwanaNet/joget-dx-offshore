1. Topologi Perangkat Keras: "Kitchen-Resilient Edge Node"
Papan Amlogic S905X dilindungi oleh boks polimer termoplastik kedap air dan uap (IP65) agar aman diletakkan di lingkungan dapur umum desa yang lembap dan panas. Karena infrastruktur kelistrikan di pedalaman sering kali tidak stabil atau padam total, perangkat ini direkayasa dengan sistem catu daya hibrida mandiri.
Selain mengandalkan sel surya mini di atap dapur, sistem dibekali dengan generator kinetik darurat yang memanfaatkan modifikasi dinamo motor pencetak (printer motor) bekas yang dirangkai mekanis dengan tuas engkol manual. Apabila terjadi pemadaman listrik total saat proses preparasi makanan di subuh hari, juru masak atau petugas pemeriksa cukup memutar engkol manual selama 60 detik. Energi mekanis tersebut diubah menjadi arus DC stabil yang disimpan di dalam sirkuit supercapacitor, memberikan daya instan bagi chip S905X untuk melewati siklus booting, membaca sensor kamera, dan mengeksekusi inferensi AI visual.
2. Alur Eksekusi Pemrosesan Citra Forensik Makanan Luring
Fase A: Ingesti Visual Alat Bukti Bahan Makanan
Sebelum makanan dimasak atau didistribusikan ke siswa, piring saji atau bahan mentah diletakkan di bawah modul kamera inspeksi. Biner Golang di dalam Armbian langsung mengunci byte-array citra mentah melalui V4L2 (Video for Linux) API.
Untuk memenuhi standar audit keuangan dan forensik kesehatan BUMN/Kementerian, citra tidak boleh diproses dalam resolusi rendah. Pipeline Golang mengeksekusi pengubahan skala (upscaling) matriks piksel gambar mentah menjadi kanvas absolut beresolusi 3000px x 3000px berkualitas stock photography.
Selanjutnya, algoritma melakukan pemotongan (cropping) geometris untuk memaksa rasio aspek vertikal berada tepat pada 9:16 (sekitar 1687px x 3000px). Standardisasi rasio vertikal 9:16 ini mutlak; ketika data berhasil disinkronisasi ke pusat, tim dokter gizi atau auditor pusat dapat meninjau foto bukti secara penuh (fullscreen) di layar smartphone mereka tanpa distorsi piksel atau pergeseran tata letak antarmuka (layout shifting).
Fase B: Inferensi Luring Higienitas & Kontaminasi (Edge SLM)
Pustaka Small Vision Model berbasis C++ NCNN memproses citra 9:16 tersebut secara luring pada RAM 1GB S905X tanpa memicu Out-Of-Memory (OOM). AI menghitung Indeks Integritas Nutrisi ($N_{integrity}$) untuk mendeteksi kontaminasi warna (pembusukan), benda asing (rambut/serangga), serta kalkulasi volume porsi:
$$N_{integrity} = \frac{1}{\mathcal{M}} \iint_{\Omega} \left( \nabla I_{3000}(x,y) \odot \Theta_{fresh}(x,y) \right) \,dx\,dy - \mu \cdot \mathcal{D}_{volume}(P_{9:16})$$
(Di mana $\nabla I_{3000}$ adalah gradien deteksi tepi kanvas resolusi tinggi untuk memisahkan batas komponen makanan, $\Theta_{fresh}$ adalah matriks klasifikasi warna luring untuk kesegaran lauk, dan $\mathcal{D}_{volume}$ adalah fungsi estimasi densitas porsi makanan pada proyeksi rasio 9:16).

4. Manajemen DOM UI & Kendali Interupsi Global Scope
Di Command Center Badan Gizi Nasional, verifikator memantau antrean visualisasi foto berorientasi vertikal 9:16 pada UI form Joget DX. Demi mengejar target SLA distribusi logistik dan kompensasi penyuplai, formulir dilengkapi hitung mundur (countdown timer) JavaScript.
Arsitektur logika hitung mundur pada komponen form builder Joget DX ini wajib mengisolasi variabel kontrolnya langsung pada tingkat global scope:
JavaScript
// Dideklarasikan pada tingkat global untuk memastikan visibilitas lintas-fungsi UI
var iv; 

function startNutritionClearanceSLA(durationInSeconds) {
    if (typeof iv !== 'undefined') clearInterval(iv);
    
    var timer = durationInSeconds;
    iv = setInterval(function () {
        // Manipulasi DOM untuk merender teks sisa waktu hitung mundur di UI...
        if (--timer < 0) {
            clearInterval(iv);
            autoApproveSupplierInvoice();
        }
    }, 1000);
}
Penerapan var iv; di luar lingkup fungsi ini merupakan sistem rem darurat. Jika dokter gizi di pusat mendeteksi kejanggalan warna pada daging atau porsi yang terlalu sedikit pada foto bukti 9:16 tersebut dan menekan tombol "Hold - Quality Anomaly Found", antarmuka Joget seketika memanggil perintah clearInterval(iv) dari fungsi tombol eksternal. Hitung mundur otomatis dibekukan seketika, mengunci data manifes secara permanen di status waiting_for_approval = 1, dan mencegah sistem mencairkan dana anggaran negara ke penyuplai nakal sebelum investigasi lapangan selesai.
