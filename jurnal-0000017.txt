1. Filosofi & Anatomi Masalah (The Inventor's Perspective)
Perusahaan keamanan siber raksasa menjual Hardware Data Diode seharga ratusan juta hingga miliaran rupiah per unit. Data diode adalah perangkat yang hanya mengizinkan data mengalir ke satu arah.
Protokol internet standar (TCP/IP) mengharuskan terjadinya komunikasi dua arah (handshake/ACK). Jika jaringan ERP (IT) meminta data ke jaringan Pabrik (OT), TCP membuka jalur dua arah, yang memungkinkan hacker menyusup masuk melalui jalur balik tersebut. Quantum-Diode memutus total kemampuan jaringan luar untuk berbicara dengan jaringan dalam secara fisik, namun tetap membiarkan data mengalir keluar secara konsisten.
2. Konsep Produk: "Peretasan Perangkat Keras yang Elegan"
Alih-alih membeli appliance mahal, kita mendayagunakan dua papan S905X bekas yang dimodifikasi secara fisik dan logis.
Arsitektur Perangkat Keras (Zero-Trust Physical Layer):
Node A (The Red Node): S905X ini diletakkan di dalam jaringan tertutup (Mesin Pabrik/Core Banking). Ia mengumpulkan data sensor atau log finansial.
Node B (The Blue Node): S905X ini diletakkan di jaringan korporat yang memiliki akses internet dan terhubung ke server Joget DX.
The Physical Hack: Kedua node ini tidak dihubungkan dengan kabel LAN, melainkan menggunakan kabel Serial USB-to-TTL. Trik jeniusnya: Anda memotong secara fisik kabel TX (Transmit) pada Node B dan kabel RX (Receive) pada Node A menggunakan tang pemotong. Secara hukum fisika, aliran listrik/data tidak akan pernah bisa kembali dari Node B ke Node A.
Pemrosesan Edge & Algoritma Forward Error Correction (FEC):
Karena tidak ada jalur balik, Node A tidak akan pernah tahu apakah paket datanya sampai di Node B dengan utuh (tidak ada TCP Acknowledge). Di sinilah kepiawaian engineering Anda masuk.
Di dalam Armbian RAM 1GB tersebut, berjalan sebuah daemon Golang atau Python yang mengemas payload JSON ke dalam blok Reed-Solomon Error Correction.
Secara matematis, jika data direpresentasikan sebagai $k$ simbol, script akan menambahkan parity $2t$, sehingga total paket yang dikirimkan secara buta melalui serial adalah $n$:
$$n = k + 2t$$

Node B menerima aliran byte yang mungkin cacat karena gangguan magnetik, namun berkat algoritma matematika FEC tersebut, ia bisa merekonstruksi payload JSON secara sempurna tanpa perlu meminta Node A mengirim ulang.
